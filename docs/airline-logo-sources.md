# Airline logo asset sources

The two airline carousels display all 30 entries visible in the supplied poster using 29 locally hosted image files retrieved on 2026-07-31. “Philippine Airlines Express” reuses the Philippine Airlines mark while “PAL Express” uses its distinct lockup. Vector files are used where a suitable source exists; the four regional or legacy marks listed as PNGs use high-resolution transparent raster sources.

The marks remain trademarks of their respective owners and are displayed only for airline identification. Their inclusion does not imply endorsement or partnership, and the site separately notes that availability depends on route and schedule.
